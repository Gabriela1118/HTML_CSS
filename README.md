# Diário de uma Apotecária
Diário de uma Apotecária é uma obra que acompanha Maomao, uma jovem que trabalha como apotecária e possui um grande conhecimento sobre ervas medicinais, venenos e medicamentos.

Após ser levada para trabalhar no palácio imperial, ela começa a solucionar mistérios e investigar acontecimentos curiosos envolvendo a família imperial.
